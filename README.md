# Curve Check

99 Small Problems · Installment 09  
Data-Rich, Insight-Poor

**Trace the evidence. Then report the IC50.** Curve Check v0.4.0 reconstructs a one-run concentration-response record from raw sample and control observations through normalization to a conditional claim. Its distinct job in the series is preserving that source-to-claim chain, not supplying another general curve fitter or comparability checklist.

The earlier 28 synthetic cases, browser-based fitting engine and false-curve experiments remain as supporting diagnostics. See the [series overlap review](docs/SERIES-OVERLAP.md) for the explicit relationship to censored-potency, Censor Check, Comparability Check, Crosstalk Check and the measurement-processing article.

## New default workflow

1. Paste or load raw CSV with `role,concentration,signal`; roles are `sample`, `neutral`, and `full`.
2. Reconstruct independent-control normalization beside sample min–max scaling of the same wells.
3. State the measured endpoint, exposure, source identifier and unverified evidence references.
4. Export a source/evidence record containing the exact original CSV, control statistics, transformations, selected numerical audit and limitations.
5. Optionally send the selected reconstruction to the curve laboratory; session JSON retains the raw-source record.

The source record is `curve-check-source-v1`. Restoring it recomputes from raw observations rather than trusting saved numerical results. The SHA-256 fingerprint identifies CSV bytes, not authentic experimental provenance. Evidence fields do not certify the assay. Records with missing controls are rejected rather than patched using sample extrema.

The default example has a true 20-unit response in a 100-unit control window, with independently adjustable well-noise SD. Zero effect is available. A constant-response baseline and free-4PL candidate are shown on the full control scale, with residual errors and a conditional AICc contrast. Effect/window fraction is not mislabeled as signal-to-noise. The comparison is not a calibrated significance test or a universal assay acceptance rule.

Version 0.4 adds three matched presets, reproducible seed/next-realization controls, and an optional known-truth overlay. The displayed experiment is labeled separately from pending settings. A fixed edge-group contrast is separated from noise-sensitive observed extrema, and draft reporting language distinguishes an unresolved relative candidate from an absolute IC50 or a claim of inactivity. Synthetic recipes survive evidence-record and curve-session handoffs; restored truth is shown only when exact regeneration matches the original raw CSV.

The revised [illustrated article](docs/ANALYSIS.md) adds midpoint sensitivity, amplitude-squared Fisher-information scaling with explicit assumptions, nuisance-parameter adjustment, and uncertainty in log-potency ratios. Three original reproducible SVG figures are generated by `scripts/build-figures.mjs`; the reference list distinguishes research, commentary, industry recommendations, official guidance, and software documentation. The user-supplied inspiration image is not included. KaTeX is a build-time development dependency; only its licensed CSS/fonts and static accessible math markup ship, not its JavaScript runtime.

To rebuild the illustrated article: `npm ci && node scripts/build-figures.mjs && node scripts/build-article.mjs && npm test`. The browser tool remains a teaching and audit prototype, not a validated bioassay analysis system.

## Use the workbench

An interactive [Perplexity preview](https://www.perplexity.ai/computer/a/curve-check-99-small-problems-GMQCvi_DQpSRlSbM7jPyJQ) is available to the owner; its sharing permissions are managed separately from repository visibility. The source can also run locally or on any static host.

```bash
python -m http.server 8000 --directory web
```

Open `http://localhost:8000`. No build, login, API key or runtime package installation is required. Serve the files over HTTP rather than opening `index.html` directly because the app uses ES modules. A module worker normally handles computation; opaque-origin previews fall back to the same engine on the browser's main thread without transmitting data.

All input data and calculations stay in the browser. An optional Fontshare stylesheet loads externally; the app remains functional with fallback fonts. It uses no analytics, remote fitting endpoint or persistent browser storage.

## What it does

- Compare a free 4PL with fixed-bottom, fixed-plateau and fixed-slope alternatives.
- Distinguish relative IC50 from a control-defined 50% response threshold.
- Display raw wells, concentration means, residuals and an approximate relative-midpoint profile likelihood.
- Expose range truncation, partial response, flat curves, high-dose reversal, shallow transitions, steep transitions, influential doses and unequal noise.
- Import one normalized concentration-response curve as CSV, including genuine zero-dose controls.
- Run leave-one-dose-out sensitivity without deleting observations from the original fit.
- Export an audit in Markdown, input data in CSV, a restorable JSON session and the dose-response chart in SVG.
- Compare identical primary sigmoids assigned to five different causes, then apply explicitly idealized interventions.
- Contrast independent-control normalization with self min–max scaling of a tiny effect.
- Inspect effect-level dose ratios for parallel and nonparallel curves.
- Read, copy or download the complete companion article inside the application.

The absolute-threshold value is a local interpolation in log concentration; its measured-dose bracket is not a confidence interval. The app does not calculate an absolute-IC50 confidence interval. It never automatically converts “50% not observed” into a claim that a finite IC50 must exist above the tested range.

## Scope and provenance

Version 0.4.0 is a research and teaching prototype, not a validated assay-analysis platform, clinical tool or regulatory acceptance standard. Its rules are declared teaching choices; they are not claimed as universally valid cutoffs. Confidence calculations assume independent, common-variance Gaussian concentration means and omit control and between-run uncertainty. Raw controls are retained and summarized but are NOT jointly fitted. No full implementation of Sebaugh recommendations, ICH validation, or USP relative-potency analysis is claimed.

The expanded scenarios are stylized counterexamples, not automatic mechanism classifiers. An artifact scenario can pass every numerical audit. The primary artifact twins share identical observations by construction. See `web/scenarios.js` for all assigned mechanisms and idealized intervention masks. Synthetic experiment sessions retain the v1 JSON schema; old sessions remain importable. The three additional algebra laboratories are independent teaching panels and are not serialized in curve-session JSON.

To rebuild the article view after editing the Markdown, run `node scripts/build-article.mjs`. The renderer is for the authored document only, not user-supplied HTML.

This installment complements, rather than replaces, [censored-potency](https://github.com/dataRichinsightPoor/censored-potency) and [Censor Check, installment 06](https://github.com/dataRichinsightPoor/censor-check). It audits a curve before a potency enters a results table; Censor Check audits what happens to censored potencies after they enter a dataset.

Only synthetic examples and original code/documentation are included. No employer-linked datasets, constructs, sequences or internal methods are included. Original material is MIT-licensed; linked literature and externally served fonts retain their own terms.
